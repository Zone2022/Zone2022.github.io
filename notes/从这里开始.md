# 从这里开始

把每一次好奇，留成一页可以再读的手记。

> 示例文档 · 这是一篇站点使用说明，用来展示 Markdown 阅读效果，可自由修改或删除。

## 一页手记的诞生

在仓库的 `notes/` 文件夹里上传 Markdown 文件，提交后等待 GitHub Pages 完成部署。新的文档会自动出现在书架上，不需要手动添加链接。

文件名会成为书架上的标题；子文件夹会成为分类。例如：

```text
notes/
├── 前端实验/
│   └── 浏览器的渲染旅程.md
├── 学习方法/
│   └── 给知识留一个入口.md
└── 设计观察/
    └── 纸张与屏幕之间.md
```

## 给文字一点结构

可以写下 **关键结论**、*还不确定的想法*，也可以用一段引用保存自己的提醒。

> 不急着写出完整答案，先把问题问清楚。

- 用二级标题整理章节，阅读器会生成文章目录。
- 代码块可以一键复制。
- 链接可以连接不同手记，例如[浏览器的渲染旅程](前端实验/浏览器的渲染旅程.md)。
- 图片放在文档旁边，通过相对路径引用。

## 发布前的小检查

- [x] 文件放在 `notes/` 内
- [x] 文件名能够说明主题
- [ ] 把示例内容换成自己的笔记
- [ ] 检查图片和链接

普通 Markdown 即可，请不要添加 Jekyll 的 `---` front matter。以下划线或点开头的文件、文件夹默认不会被 Jekyll 收录。
